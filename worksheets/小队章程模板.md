# 小队章程模板（第 1 次课签署）

> 双元制模拟企业项目小队。签署后即为小队"内部宪法"，全学期有效，违者按 §4 处理。

小队名称：________ 命名空间：team{n}-dev 成员与角色：

| 成员 | 角色 | 职责 |
|---|---|---|
| | PO（产品负责人） | 需求澄清、任务拆分、对外发言 |
| | 后端工程师 | 表设计/子图实现/安全改造 |
| | 前端工程师 | 页面联调/E2E 用例 |
| | 测试工程师 | 压测/回归/报告 |

## §1 工作守则（对照企业）

1. 文档、代码、账号密码不得外传（等保合规）
2. 每次课开始 5 分钟开小队站会：昨天做了什么/今天做什么/有什么阻塞
3. 所有操作先 `kubectl get` 确认 namespace——**绝不触碰 team{n}-dev 之外**
4. 工件当天入档：任务单 + 费曼卡 + 代码提交

## §2 协作约定

1. 分歧裁决：PO 主持，导师质询后投票，2:1 生效
2. 缺席：提前告知 PO；缺任务单 2 次触发导师谈话
3. 角色轮换：每 4 次课轮换一次角色（双元制多面手培养）

## §3 质量门禁

1. 代码：导入冒烟通过才可提交
2. 接口：SDL 评审通过才可编码
3. 上线：探针通过才可注册网关

## §4 违约处理

1. 泄密/违规操作：立即上报导师，按校纪处理
2. 连续两次任务延误：导师介入调整分工
