# 11 安全合规与等保三级设计

> 依据：GB/T 22239-2019（三级）、《个人信息保护法》《数据安全法》、GB/T 43697-2024 数据分类分级、GM/T 国密系列。

---

## 1. 数据分类分级（先行——一切安全的输入）

| 级别 | 数据示例 | 处置要求 |
|---|---|---|
| S4 敏感个人信息 | 手环位置轨迹、健康告警、身份证号 | **单独同意**、SM4 字段加密、独立库 `szxc_sensitive`、独立账号、访问审计到人、保留期限明示 |
| S3 个人信息 | 姓名、手机号、实住址 | SM4 加密存储、展示脱敏（138****5678）、最小可见范围 |
| S2 内部业务 | 事件单、积分、订单、统计 | 常规保护、按 ABAC 范围可见 |
| S1 公开 | 三务公开、资讯、指南 | 完整性保护+发布审核 |

**医疗红线**：远程医疗仅做预约与会议转接，**不采集不存储诊疗数据**（电子健康档案留在卫健系统，界面内嵌跳转）；页面明示免责与提示。
**积分商城红线**：兑换履约闭环（发货/完成确认）、对账与退款路径、不涉及现金充值（避开预付卡监管），如未来开通现金充值需支付牌照或持牌合作（合规建议已写入风险清单）。

## 2. 等保三级技术要求对照（安全计算环境/区域边界/通信网络/管理中心，逐项落地）

| 要求域 | 标准条款要求 | 本系统落地 |
|---|---|---|
| 身份鉴别 | 双因子、口令复杂度、失败锁定 | 密码+短信/微信双因子（管理端强制）；锁定 5 次/15min |
| 访问控制 | 最小权限、默认拒绝 | RBAC+ABAC（04号）；K8s RBAC 按 namespace 隔离；NetworkPolicy 默认拒绝 |
| 安全审计 | 全量审计、防篡改、存 6 个月以上 | 写操作+管理操作审计事件入独立表（只插入，WORM 化导出）；保留 3 年在线 |
| 入侵防范 | 最小安装、漏洞扫描 | Distroless 镜像、非 root 运行、只读根文件系统；每周 Trivy 扫描 CI 门禁 |
| 恶意代码 | 防护 | 上传文件类型白名单+魔数校验+ClamAV 异步扫描 |
| 数据完整性 | 传输与存储完整性 | TLS1.3；溯源链 SM3 哈希链；关键表 checksum 对账 |
| 数据保密性 | 加密存储 | SM4 字段级（S3/S4）+ 传输 TLS；密钥分层（根密钥-数据密钥）|
| 数据备份 | 异地/离线 | BR 每日全量+NFS 离线副本（异地建议后续追加） |
| 剩余信息保护 | 内存/存储清除 | 容器临时文件 tmpfs；销毁流程覆盖介质 |
| 个人信息保护 | 告知同意、最小必要、可撤回 | 隐私政策+单独同意工作流；撤回即停采集+导出/删除请求通道（30 日响应） |
| 边界防护 | 入口控制、入侵检测 | 网关限流+WAF 规则（ModSecurity 规则集，域名就绪后启用）；出口白名单 |
| 集中管控 | 安全管理中心 | 统一审计中心（audit 事件汇聚）+ 集中告警（Alertmanager） |

## 3. 国密套件应用

| 场景 | 算法 | 实现 |
|---|---|---|
| 口令存储 | SM3+盐(迭代) | 自研 `Sm3PasswordEncoder`（BC 库） |
| S3/S4 字段加密 | SM4-GCM | 数据密钥每表独立，根密钥 KMS 外置（一期 Secret+流程管控） |
| 电子证明签发 | SM2 数字签名 + 可信时间戳 | 证明 PDF 带 SM2 签名，核验页公钥校验 |
| 溯源锚定 | SM3 哈希链 | 每环节 prevHash 链式，根哈希日度公示 |
| 传输 | TLS1.3（国密 SSL 可选双证书） | 域名+网关就绪后配置 GMSSL 或双栈 |

## 4. 应用安全（SDL 要点）

- 威胁建模（STRIDE）每域过一遍（执行阶段产出威胁模型文档，重点：事件上报防越权查看、积分防重放、IoT 指令防伪造）。
- OWASP Top10 覆盖：注入（参数化+输入校验）、失效鉴权（网关统一+SDL 内省禁用）、SSRF（出站白名单）、文件上传（类型/大小/隔离存储）、GraphQL 特有（深度/批量查询限制、字段级授权、禁内省生产）。
- 依赖安全：OWASP Dependency-Check + Trivy，CVSS≥7 阻断发布。
- 密钥管理：不入代码库（gitleaks 扫描）、不入镜像；Secret 最小权限。
- AI 安全：提示注入防护与红队集（07 号文档 §7）。

## 5. 安全测试与测评路径

1. 自测：ZAP 基线扫描（CI 每周）+ 上线前渗透测试（第三方）；
2. 等保测评：定级备案（三级）→ 差距分析（对照 §2 表）→ 整改 → 测评机构现场测评 → 备案证明；
3. 交付物：安全方案、测评支撑材料、整改报告。
