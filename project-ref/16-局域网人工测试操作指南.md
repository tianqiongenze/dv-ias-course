## 三、管理端测试（约 15 分钟，与 H5 联动）

打开 http://10.167.2.175:31202/admin ，用 `13900000001 / szxc@2026` 登录县管理员。

### 3.1 治理看板

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 登录后进入"治理看板" | 显示事件 KPI（总数/待办/办结率）与 6 个村对比条形图 |
| 2 | 与 H5 首页指标对照 | 两端数字一致（同一 data-svc 数据源） |

### 3.2 事件处置（核心闭环，使用 2.3 记下的编号）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 切到"事件处置"，找到刚才上报的事件（状态"待受理"） | 列表按状态/村庄筛选 |
| 2 | 点【受理】 | 状态变 **accepted** |
| 3 | 点【派单】 | 状态变 **dispatched** |
| 4 | 点【处置完成】（可填备注） | 状态变 **resolved** |
| 5 | 点【审核通过】 | 状态变 **approved**，村民自动 +20 积分 |
| 6 | 回 H5"我的"看积分 | 余额增加 20（幂等：不会重复加分） |

> 状态机校验：跳步操作（如未受理直接审核）会被拒绝并提示错误——可故意试一次验证。

### 3.3 公开发布

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 切到"公开发布"，选村"清溪村"、栏目" notice"、标题"测试公告"、正文随意 | 发布成功 |

## 五、GraphQL 网关直测（开发者/技术验收，可选）

用 Postman / curl 向 `http://10.167.2.175:30085/` POST：

**1) 登录取 token：**
```json
{"query": "mutation { login(phone: \"13800000001\", password: \"szxc@2026\") { token name } }"}
```

**2) 联邦跨域组合查询**（iam 实体 + points 子图字段一次取回，带 Authorization: Bearer <token>）：
```json
{"query": "{ party(id: 58) { name pointsAccount { balance } } }"}
```
预期返回 `"party": {"name": "王村民01", "pointsAccount": {"balance": ...}}` —— 跨服务数据一次往返。

**3) 限流验证**：同一 token 1 分钟内连发 >6000 次后，返回 `RATE_LIMITED 请求过于频繁`。

## 六、常见问题（FAQ）

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面偶发打不开/转一下就好 | 集群跨节点负载均衡抖动（已修复 rp_filter，偶发余留） | 刷新重试；持续不通联系运维 |
| 登录提示"请求过于频繁" | 触发 6000/min 限流 | 等待 1 分钟再试 |
| 首页指标为 0 或空 | data-svc 缓存过期回源中 | 刷新一次即可 |
| H5 显示"网络错误" | H5 默认指向 10.167.2.175:30085；若网关地址变更 | 浏览器控制台执行 `localStorage.setItem('dv_gw','http://10.167.2.175:30085')` 后刷新 |
| AI 问答回复"请描述您的问题" | 本地大模型（qwen2.5:14b）未命中或降级到 FAQ | 属降级链设计，功能正常 |
| 事件流转按钮点不动 | 角色权限不足（如网格员不能审核） | 换县管理员 13900000001 登录 |
