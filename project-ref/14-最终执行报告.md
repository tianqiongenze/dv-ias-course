## 三、全链路验证结果（通过网关 30085 实测）

1. **登录**：SM3 手机号哈希 + SM3-PBKDF2 口令校验 → JWT（✅）
2. **随手拍上报**：reportEvent → 事件号 EVT2026…（✅）
3. **事件流转**：accept → dispatch → resolve → approve，状态机严格校验（✅）
4. **积分入账**：审批通过后 points-svc 3s 轮询入账，环境类 +20 分，
   幂等键 uk_ref 防重复（重复入账 0）（✅）
5. **联邦跨域**：`party(id) { name pointsAccount { balance } }` —— iam 实体 + points
   子图贡献字段一次查询组合成功（✅）
6. **指标快照**：data-svc 读池查询 + 多级缓存，villager_total=43、event_total 等
   全部返回（✅）
7. **限流/安全**：网关 JWT 校验 + 身份头注入（x-user-name Base64 编码防 ByteString
   非法字符）、600req/min 令牌桶、INTERNAL 错误对外脱敏（✅）

## 六、安全与合规落点

- 敏感字段（手机号）SM4-GCM 加密存储于独立字段，口令 SM3-HMAC 派生（国密），
  JWT HS256 签名；网关强制剥离客户端伪造身份头。
- MCP 工具调用全部审计入库（szxc_biz.mcp_audit）。
- 等保三级控制项映射见《12-安全等保.md》。

## 七、与设计文档的偏差

1. 事件跨服务通知：MVP 采用 HTTP 轮询（governance /internal/approved → points），
   Pulsar topic 已预建，一期切换（ADR-007-D4）。
2. 读写分离 MVP 为账号级双连接池（rw/ro 双账号），未拆只读 TiKV 实例（ADR-007-D3）。
3. RAG 为进程内语料（8 条知识）+ LiteLLM 本地 qwen2.5:14b 降级链（ADR-007-D5）。
