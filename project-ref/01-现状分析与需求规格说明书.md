## 4. 功能需求（FR，按域列举核心用例，完整用例见 04 号文档）

### 4.1 身份与组织域（IAM）
- FR-101 组织管理：县-乡-村-组-户 五级组织树，CRUD + 批量导入（Excel/CSV）
- FR-102 账号体系：村民（手机号+实名）、村干部（账号+角色）、管理员；微信小程序一键登录
- FR-103 权限：RBAC 角色 + ABAC 数据范围（本人/本户/本组/本村/本乡/全县）
- FR-104 多租户：按县域隔离，tenant_id 全局维度

### 4.2 乡村治理域
- FR-201 网格：网格员-网格绑定、巡查打卡（GPS）
- FR-202 事件：村民随手拍上报（图片+GPS+描述）→ 受理 → 派单 → 处置（拍照反馈）→ 审核 → 评价；超时升级
- FR-203 公开：村务/财务/党务三公开，栏目化发布、附件、定时发布
- FR-204 投票：议题发起、资格校验、匿名投票、结果公示（防重：一人一票幂等）
- FR-205 积分：行为规则引擎（参与治理/环保/志愿加分，违规减分）、积分流水、排行
- FR-206 人居环境 AI：摄像头截图接入 → 异常识别（垃圾堆放/违停）→ 生成治理事件（人工复核后立案）

### 4.3 智慧农业域
- FR-301 地块档案：地块 GIS 边界、种植作物、农户归属
- FR-302 农事：种植计划、农事记录（播种/施肥/灌溉/采收）
- FR-303 IoT：设备注册、遥测入库（Pulsar→时序存储）、阈值告警、远程控制（灌溉/补光，双人复核指令）
- FR-304 病虫害识别：拍照上传 → 图像分类 → 结论+处置建议
- FR-305 产销对接：市场价格采集、供需发布、推荐匹配

### 4.4 公共服务域
- FR-401 办事指南分类检索、智能问答引导
- FR-402 证明开具：在线申请 → 村审核 → 电子证明（PDF+签名/时间戳）→ 下载核验
- FR-403 补贴查询：个人涉农补贴列表（政务共享接口，异常降级为申报制）
- FR-404 一老一小：手环设备绑定、实时位置（敏感，单独同意+加密）、跌倒/ SOS 告警 → 网格员工单、儿童课程预约
- FR-405 远程医疗：仅预约挂号 + 视频会诊转接（会议室链接），**不存储诊疗数据**

### 4.5 乡村文旅域
- FR-501 景点/民宿档案、720°全景素材管理
- FR-502 预约（分时段库存）、核销（二维码）、支付对接（微信/支付宝，可配置模拟支付）
- FR-503 导览：手绘地图点位、路线推荐、TTS 语音讲解
- FR-504 一码通：聚合码生成与核销记录

### 4.6 AI 智能体域（数字乡村大脑）
- FR-601 RAG 问答：政策/农技/办事知识库检索增强问答，答案带引用溯源
- FR-602 办事助手：多轮对话引导 → 直达办事入口（意图识别 + 工具调用）
- FR-603 治理辅助：事件自动分类/派单建议、公开内容合规检查
- FR-604 MCP 工具：查询积分/办事进度/天气/价格等以 MCP server 形式供智能体调用
- FR-605 运营看板：大屏指标（20+ 核心指标实时刷新）

## 6. 运行环境与约束

- 环境：上述 K8s 集群；项目命名空间 `szxc-prod` / `szxc-dev`。
- 端口预算：网关 NodePort **30085**（GraphQL）、30086 预留大屏 WebSocket（如需）。
- 资源预算：命名空间 ResourceQuota：requests 合计 ≤ 40C/80G（为共享租户留余量）。
- 外部依赖：短信网关（可配置模拟）、微信开放平台（小程序，可先 H5）、CDN（建议，可后补）、支付（一期可模拟支付）。
- 假设与依赖：政务共享接口不可用时不阻塞主线（降级为申报/公示制）。

## 7. 验收准则（摘要，详见 13 号文档）

1. 功能：04 号文档全部 MVP 用例 BDD 场景通过；
2. 性能：13 号文档 k6 场景达 SLO；
3. 质量：核心域单测行覆盖 ≥ 80%，SonarQube 0 阻断；
4. 安全：11 号文档等保三级技术对照表全部"已实现"；
5. 交付物：代码（Monorepo）+ 镜像 + 部署清单 + 运维手册 + 培训材料。
